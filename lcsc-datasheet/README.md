# lcsc-datasheet

Search electronic components on [LCSC](https://www.lcsc.com/) and download datasheets.

## Dependencies

- Python 3.10+
- `requests` is used if available, otherwise falls back to `curl` automatically

## Usage

Ask your agent:

- "Download the datasheet for AW36514"
- "Search LCSC for a 3.3V LDO in SOT-23"
- "Find the datasheet for LCSC part C506187"
- "What 0603 10kΩ resistors are available on LCSC?"
